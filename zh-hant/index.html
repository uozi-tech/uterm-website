Mac 和 iPhone 上的
SSH 終端機與伺服器工具

終端機採用 Ghostty 引擎。檔案管理、連接埠轉送、金鑰、多主機平行執行和 AI 助理都在同一個 App 裡，iPhone 還能遠端控制 Mac。原始碼以 AGPL-3.0 開放，無須註冊帳號。

下載 macOS 版 iPhone 與 iPad 版（公開測試）

macOS 26 以上（Apple 晶片）· iOS／iPadOS 18 以上 · AGPL-3.0

終端機

終端機以 Ghostty 引擎透過 GPU 繪製，大量輸出時捲動依然流暢；Claude Code、Codex 等全螢幕程式的顯示與在 Ghostty 中一致。

  • 分頁與分割畫面

    拖移分頁即可分割畫面，重新啟動後依原本的版面還原。

  • 重新啟動後接回終端機

    本機終端機由獨立的處理程序持有。uTerm 更新或意外結束後重新打開，終端機裡的程式不受影響。

  • 斷線後自動接回

    在 iPhone 上，shell 會留在主機上執行。重新連線後自動接回，並補上中斷期間的輸出。

檔案、轉送、金鑰與批次執行

管理伺服器常用的幾項工具，和終端機放在一起。

SFTP 視窗

獨立的檔案視窗，支援多個分頁、拖放上傳下載，以及多路平行傳輸。檔案可用本機 App 打開，儲存後自動傳回主機；SQLite 資料庫可交給 uTable 開啟。

預覽與編輯

在工作區中打開遠端檔案，支援語法突顯、Markdown 和圖片預覽，編輯後按 ⌘S 儲存回主機。終端機就在同一個視窗下方。

連接埠轉送

支援本機、遠端和 SOCKS 轉送。所有主機的規則集中在同一個面板中，可設為隨 uTerm 啟動自動建立。

多主機平行執行

在選定的主機上同時執行同一個指令，每台主機的輸出分格顯示，也可以轉到背景執行。某台出錯時，可交給 AI 繼續排查。

主機與群組

依用途分組，支援跳板主機。新增時可以先測試連線，也可以複製現有主機，或從 ~/.ssh/config 匯入。

快速指令

儲存常用指令並指定目標主機，執行紀錄保留 30 天。也可以只描述目標，交給 AI 執行。

金鑰

產生或匯入 Ed25519、RSA、ECDSA 金鑰，支援有密語保護的私密金鑰。金鑰存放在鑰匙圈中，並透過 iCloud 鑰匙圈同步。

已知主機指紋

首次連線時核對主機指紋，指紋變更時阻擋連線。已儲存的指紋可以在這裡查看和刪除。

iPhone 與 iPad

終端機、檔案、連接埠轉送、快速指令和 AI 助理在 iPhone 與 iPad 上同樣可用，主機和金鑰透過 iCloud 同步。iPhone Duo 展開或橫向握持時採用大螢幕排版。

  • 工作階段留在主機上

    shell 由主機上的保持程序執行。切到背景、切換網路，或 App 被系統結束後，回來時都會自動接回，並補上中斷期間的輸出。

  • 鍵盤列

    提供 esc、tab、ctrl 和方向鍵，可填入 claude、codex 等常用指令，還能把剪貼簿或相簿裡的圖片、影片傳送給主機上的 AI 程式。

  • 動態島與背景執行

    Claude Code 等待確認、完成或出錯時，狀態會顯示在動態島和鎖定畫面上。長按分頁選擇「離開後繼續執行」，切換到其他 App 後連線仍會保持。

  • 分頁與分割畫面

    終端機和檔案分頁位於同一個工作區，可拖移分成兩欄；回捲內容支援搜尋。

遠端控制 Mac

在 iPhone 上繼續使用 Mac 上開著的終端機，或查看並操作 Mac 的螢幕。另一台 Mac 也可以當作控制端。

終端機鏡像Mac 上新開的終端機會自動出現在手機上，兩端可以同時輸入，畫面逐格一致，Claude Code 的執行狀態也會同步。
遠端桌面硬體編碼、低延遲、含聲音。可切換顯示器、放大至 8 倍；沒有接顯示器的 Mac 會依手機螢幕建立虛擬顯示器。
手勢提供觸控式軌跡板與觸控螢幕兩種模式，三指滑動可切換桌面、打開指揮中心。
遠端解鎖可以在手機上輸入密碼來解鎖 Mac，或通過系統的驗證視窗。密碼只儲存在手機上，使用時需要 Face ID 驗證。
Mac 上的檔案無須開啟 SSH，即可瀏覽、上傳和下載已配對 Mac 上的檔案。也可以把本機的檔案夾分享給受控的 Mac，預設為唯讀。
用 Mac 控制 Mac以另一台 Mac 當作控制端時，螢幕、終端機和單一視窗查看都同樣可用。
裝置群組手機、平板和 Mac 加入同一個裝置群組後，群組內任一台裝置確認即可加入新裝置，不必逐台配對。
更新時不中斷遠端控制在獨立的背景處理程序中執行，Mac 上的 uTerm 更新或意外結束時，現有連線不受影響。
2.4 新功能

視窗模式

只查看 Mac 上的單一視窗。Mac 會把該視窗調整成適合手機螢幕的尺寸，內容隨之重新排版；離開後視窗會恢復原本的大小。

  • 文字大小

    選「最清晰」時，Mac 的像素與手機一對一對應；選「標準」時，文字與在 Mac 上一樣大，也可以再調大。

  • 觸控螢幕模式

    直接點一下目標位置。單指拖移為捲動，按住後拖移為拖放，雙指輕點為按右鍵。

  • 獨立鍵盤滑鼠

    輸入直接傳給該視窗，Mac 上的指標不會移動，視窗被遮住時也能操作；Mac 前面的使用者可以同時使用自己的鍵盤和滑鼠。

  • 保持在最前面

    視窗被遮住時，macOS 會暫停重繪。開啟此項目後，查看期間該視窗會一直保持在最前面。

區域網路直連

在同一個網路內直接連線，延遲最低。

點對點連線

不在同一個網路時，會先嘗試打洞直連，不經過伺服器。

自架中繼

無法直連時，透過你自行部署的中繼轉送。中繼只轉送加密資料，無法讀取內容。

AI 助理

助理在目前的主機上執行指令、讀取結果，再決定下一步。每個指令都會依你設定的安全等級確認後才執行。

  • 安全等級

    可選「每步確認」「唯讀自動」和「AI 代批」。涉及敏感操作或無法判斷風險的指令，一律需要人工確認。

  • 模型服務

    使用你自己的 API Key 接入 Anthropic、OpenAI 或相容介面，可選擇模型和思考深度。

  • 供其他 AI 程式設計工具使用

    可以在設定中為 Claude Code、Codex、Cursor、CodeBuddy 和 Antigravity 安裝 uTerm 技能。這些工具會透過 uTerm 使用已儲存的主機來執行指令、傳輸檔案和建立隧道，不必取得密碼。

# 用 uTerm 操作远程主机

所有功能

依類別列出 uTerm 目前的所有功能。

終端機

  • Ghostty 引擎、GPU 繪製，Claude Code、Codex 等全螢幕程式正確顯示
  • 分頁、拖移分割畫面，重新啟動後還原版面
  • 本機終端機和 SSH 終端機在 uTerm 重新啟動、更新後自動接回
  • 在回捲內容中搜尋（⌘F）
  • Claude／Codex 的執行狀態顯示在分頁上，需要你處理時發出通知
  • 關閉仍有程式在執行的分頁前先確認
  • 終端機 ⇄ Agent 一鍵切換

檔案

  • SFTP 視窗與工作區側邊欄，多個分頁
  • 拖放上傳下載，多路平行傳輸
  • 預覽、直接編輯，按 ⌘S 儲存回主機
  • 用本機 App 打開，儲存後自動傳回
  • SQLite 資料庫交給 uTable 開啟
  • 刪除檔案夾時顯示進度，可以中途取消

主機與連線

  • 群組、置頂、搜尋、鍵盤操作
  • 跳板主機、測試連線、複製為新主機
  • 從 ~/.ssh/config 匯入
  • Ed25519／RSA／ECDSA 金鑰，存放在鑰匙圈
  • 核對已知主機指紋
  • 連接埠轉送 -L／-R／SOCKS，可隨啟動自動建立

AI

  • Agent 執行指令、讀取結果並給出結論
  • 每步確認／唯讀自動／AI 代批三個等級
  • 執行卡片：核准、進度、輸出、結束代碼
  • 接入自己的模型服務，可選模型和思考深度
  • 需要互動的指令在新的終端機視窗中執行
  • 對話紀錄，預設保留 180 天

命令列與技能

  • SFTP 讀寫與續傳，新增或刪除連接埠轉送

  • 存取已配對 Mac 上的檔案

遠端控制

  • 多顯示器、放大 8 倍、虛擬顯示器

  • 區域網路直連、打洞、自架中繼

iPhone 與 iPad

  • 動態島、鎖定畫面狀態，離開後繼續執行
  • 鍵盤列：常用按鍵、指令短語、傳送圖片和影片

隱私權

uTerm 不經營任何存放使用者資料的伺服器。

無須帳號

安裝後即可使用，不需要註冊或登入。

不收集資料

App 中沒有任何分析或追蹤。資料只會儲存在你的裝置和你的 iCloud 中。

鑰匙圈

密碼和私密金鑰儲存在系統鑰匙圈中，可開啟 Face ID 或 Touch ID App 鎖定。

開放原始碼

App 和中繼的原始碼都以 AGPL-3.0 開放，你可以自行稽核和部署。

常見問題

iPhone 與 iPad 版要怎麼安裝？

目前透過 TestFlight 公開測試。在 iPhone 或 iPad 上安裝 TestFlight 後，打開邀請連結加入，之後的測試版會自動推送。

和 Termius 這類工具相比有什麼不同？

uTerm 無須帳號，資料透過你自己的 iCloud 同步，不經過第三方伺服器。它是 Mac 與 iOS 的原生 App，內建可執行指令的 AI 助理，並支援用手機遠端控制 Mac 的終端機和螢幕。

支援 Windows 或 Linux 嗎？

目前只支援 macOS（Apple 晶片）和 iOS／iPadOS。伺服器端沒有限制，只要能以 SSH 登入的主機都可以連線。

遠端控制 Mac 需要什麼？

Mac 和手機都需要安裝 uTerm。首次配對時，在 Mac 上輸入手機顯示的核對碼。在同一個區域網路內會直接連線；跨網路時先嘗試點對點連線，失敗時再透過你自行部署的中繼（一行指令就能安裝到你的伺服器上）。

AI 助理會把我的資料傳到哪裡？

只會傳給你設定的模型服務，並使用你的 API Key。沒有設定時，不會傳送任何內容。

要在哪裡回報問題？

請在 GitHub Issues 提交。安全性問題請依照 SECURITY.md 私下回報。

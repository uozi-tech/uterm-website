Mac と iPhone のための
SSH ターミナルとサーバツール

ターミナルには Ghostty エンジンを採用。ファイル管理、ポートフォワーディング、鍵、複数ホストでの並列実行、AI アシスタントをひとつの App にまとめ、iPhone から Mac をリモート操作することもできます。コードは AGPL-3.0 で公開しており、アカウント登録は不要です。

macOS 版をダウンロード iPhone / iPad 版（パブリックベータ）

macOS 26 以降（Apple シリコン）· iOS / iPadOS 18 以降 · AGPL-3.0

ターミナル

ターミナルは Ghostty エンジンにより GPU で描画されます。大量の出力でもスクロールは滑らかで、Claude Code や Codex などのフルスクリーンプログラムも Ghostty と同じように表示されます。

  • タブと分割表示

    タブをドラッグするだけで画面を分割。再起動しても元のレイアウトに戻ります。

  • 再起動してもターミナルはそのまま

    ローカルのターミナルは独立したプロセスが保持します。uTerm のアップデート後や予期せず終了した後に開き直しても、ターミナル内のプログラムは動き続けます。

  • 切断されても自動で復帰

    iPhone では、シェルはホスト上で動き続けます。再接続すると自動的に復帰し、切断中の出力も補われます。

ファイル、転送、鍵、一括実行

サーバ管理でよく使うツールを、ターミナルと同じ場所に。

SFTP ウインドウ

独立したファイルウインドウ。複数タブ、ドラッグ＆ドロップによるアップロード／ダウンロード、複数経路での並列転送に対応します。ファイルは手元のアプリで開け、保存するとホストに自動で書き戻されます。SQLite データベースは uTable で開けます。

プレビューと編集

リモートファイルをワークスペースで開いて、シンタックスハイライト、Markdown、画像をプレビュー。編集したら ⌘S でホストに保存できます。ターミナルは同じウインドウの下部にあります。

ポートフォワーディング

ローカル、リモート、SOCKS のフォワーディングに対応。すべてのホストのルールをひとつのパネルで管理でき、uTerm の起動時に自動で確立するよう設定することもできます。

複数ホストでの並列実行

選んだホストで同じコマンドを同時に実行し、出力はホストごとに分けて表示。バックグラウンドに回すこともできます。エラーが出たホストは、AI に調査を引き継げます。

ホストとグループ

用途ごとにグループ分けでき、踏み台ホストにも対応。新規作成時に接続をテストできるほか、既存のホストを複製したり、~/.ssh/config から読み込んだりすることもできます。

クイックコマンド

よく使うコマンドを保存して、対象のホストを指定。実行履歴は 30 日間保存されます。やりたいことを説明するだけで、AI に実行させることもできます。

鍵

Ed25519、RSA、ECDSA の鍵を生成またはインポートでき、パスフレーズ付きの秘密鍵にも対応します。鍵はキーチェーンに保存され、iCloud キーチェーンで同期されます。

既知のホストのフィンガープリント

初回接続時にホストのフィンガープリントを照合し、変わっていれば接続をブロックします。保存済みのフィンガープリントはここで確認・削除できます。

iPhone と iPad

ターミナル、ファイル、ポートフォワーディング、クイックコマンド、AI アシスタントは iPhone と iPad でも使えます。ホストと鍵は iCloud で同期。iPhone Duo では、開いたときや横向きにしたときに大画面向けのレイアウトになります。

  • セッションはホストに残る

    シェルはホスト上の常駐プロセスが実行します。バックグラウンドに切り替えたり、ネットワークが変わったり、App がシステムに終了されたりしても、戻ると自動的に復帰し、切断中の出力も補われます。

  • キーボードバー

    esc、tab、ctrl、矢印キーを備え、claude や codex などのよく使うコマンドもすぐに入力できます。クリップボードや写真ライブラリの画像・ビデオを、ホスト上の AI プログラムに送ることもできます。

  • ダイナミックアイランドとバックグラウンド実行

    Claude Code が確認待ちになったとき、完了したとき、エラーが起きたときに、その状態をダイナミックアイランドとロック画面に表示します。タブを長押しして「離れても実行を継続」を選ぶと、ほかの App に切り替えても接続が保たれます。

  • タブと分割表示

    ターミナルとファイルのタブは同じワークスペースに並び、ドラッグして 2 列に分割できます。スクロールバックも検索できます。

Mac をリモート操作

Mac で開いているターミナルを iPhone でそのまま使ったり、Mac の画面を見ながら操作したりできます。別の Mac から操作することもできます。

ターミナルミラーリングMac で新しく開いたターミナルは、自動的にスマートフォンにも表示されます。両方から同時に入力でき、画面は 1 マスまで一致。Claude Code の実行状態も同期されます。
リモートデスクトップハードウェアエンコードによる低遅延の画面転送で、音声も届きます。ディスプレイの切り替えや最大 8 倍の拡大に対応し、ディスプレイがつながっていない Mac ではスマートフォンの画面に合わせた仮想ディスプレイを作成します。
ジェスチャトラックパッドモードとタッチスクリーンモードを用意。3 本指でスワイプすると、デスクトップの切り替えや Mission Control の表示ができます。
リモートでロック解除スマートフォンでパスワードを入力して、Mac のロックを解除したり、システムの認証ダイアログを通過したりできます。パスワードはスマートフォンにのみ保存され、使うときは Face ID による認証が必要です。
Mac 上のファイルSSH を有効にしなくても、ペアリング済みの Mac 上のファイルを閲覧、アップロード、ダウンロードできます。手元のフォルダを操作先の Mac に共有することもでき、デフォルトでは読み取り専用です。
Mac から Mac を操作別の Mac から操作するときも、画面、ターミナル、単一ウインドウの表示を同じように使えます。
デバイスグループスマートフォン、タブレット、Mac を同じデバイスグループに入れておけば、新しいデバイスはグループ内のどれか 1 台で承認するだけで追加できます。1 台ずつペアリングする必要はありません。
アップデートしても切れないリモート操作は独立したバックグラウンドプロセスで動作します。Mac 上の uTerm がアップデートされたり予期せず終了したりしても、確立済みの接続には影響しません。
2.4 の新機能

ウインドウモード

Mac 上のウインドウをひとつだけ表示します。Mac はそのウインドウをスマートフォンの画面に合うサイズに変更し、内容もそれに合わせてレイアウトし直されます。終了すると、ウインドウは元のサイズに戻ります。

  • 文字サイズ

    「最も鮮明」では Mac のピクセルとスマートフォンのピクセルが 1 対 1 で対応し、「標準」では文字が Mac 上と同じ大きさになります。さらに大きくすることもできます。

  • タッチスクリーンモード

    目的の場所を直接タップ。1 本指でドラッグするとスクロール、長押ししてからドラッグするとドラッグ操作、2 本指でタップすると右クリックになります。

  • 独立したキーボードとマウス

    入力はそのウインドウに直接送られ、Mac のポインタは動きません。ウインドウがほかのウインドウに隠れていても操作でき、Mac の前にいる人は自分のキーボードとマウスを同時に使えます。

  • 最前面に保つ

    ウインドウが隠れていると、macOS は再描画を止めてしまいます。この設定をオンにすると、表示している間はそのウインドウが常に最前面に置かれます。

ローカルネットワークで直接接続

同じネットワーク内では直接つながるので、遅延が最も小さくなります。

ピアツーピア接続

同じネットワークにいないときは、まずホールパンチングによる直接接続を試みます。サーバは経由しません。

セルフホストのリレー

直接接続できないときは、自分で設置したリレーを経由して転送します。リレーは暗号化されたデータを中継するだけで、内容を読み取ることはできません。

AI アシスタント

アシスタントは現在のホスト上でコマンドを実行し、結果を読んでから次の手順を決めます。各コマンドは、設定した安全レベルに従って確認されてから実行されます。

  • 安全レベル

    「毎回確認」「読み取り専用は自動」「AI が承認」から選べます。機密性の高い操作や、リスクを判断できないコマンドは、常に人による確認が必要です。

  • モデルサービス

    自分の API キーで Anthropic、OpenAI、または互換 API に接続でき、モデルと思考の深さを選べます。

  • ほかの AI コーディングツールからも使える

    設定から Claude Code、Codex、Cursor、CodeBuddy、Antigravity に uTerm スキルをインストールできます。これらのツールは uTerm を通じて保存済みのホストを使い、コマンドの実行、ファイルの転送、トンネルの確立を行います。パスワードを渡す必要はありません。

~/.claude/skills/uterm/SKILL.md
---
name: uterm
description: 通过 uTerm 使用用户已保存的 SSH 主机：执行远程命令（单机 run、
  多机并行 run-many、快捷命令）；经 SFTP 读写远程文件；新建、启停端口转发；
  查看用户开着的终端会话 …
---

# 用 uTerm 操作远程主机

地址、密码、私钥、口令、跳板机配置全程留在 uTerm 和钥匙串里，
你一个字节也拿不到，也不需要。

すべての機能

uTerm の現在の機能をカテゴリ別にまとめました。

ターミナル

  • Ghostty エンジンによる GPU 描画、Claude Code や Codex などのフルスクリーンプログラムも正しく表示
  • タブとドラッグによる分割、レイアウトは再起動後に復元
  • ローカルと SSH のターミナルは、uTerm の再起動やアップデート後に自動で復帰
  • スクロールバック内の検索（⌘F）
  • Claude / Codex の実行状態をタブに表示し、対応が必要なときは通知
  • プログラムが動いているタブを閉じる前に確認
  • ターミナル ⇄ Agent をワンクリックで切り替え

ファイル

  • SFTP ウインドウとワークスペースのサイドバー、複数タブ
  • ドラッグ＆ドロップでアップロード／ダウンロード、複数経路で並列転送
  • プレビュー、直接編集、⌘S でホストに保存
  • 手元のアプリで開き、保存すると自動で書き戻し
  • SQLite データベースは uTable で開く
  • フォルダ削除時は進行状況を表示、途中でキャンセル可能

ホストと接続

  • グループ、ピン留め、検索、キーボード操作
  • 踏み台ホスト、接続テスト、新しいホストとして複製
  • ~/.ssh/config から読み込み
  • Ed25519 / RSA / ECDSA 鍵、キーチェーンに保存
  • 既知のホストのフィンガープリントを照合
  • ポートフォワーディング -L / -R / SOCKS、起動時に自動確立も可能

AI

  • Agent がコマンドを実行し、結果を読んで結論を提示
  • 毎回確認 / 読み取り専用は自動 / AI が承認 の 3 段階
  • 実行カード：承認、進行状況、出力、終了コード
  • 自分のモデルサービスに接続、モデルと思考の深さを選択
  • 対話が必要なコマンドは新しいターミナルウインドウで実行
  • 会話履歴、デフォルトで 180 日間保存

コマンドラインとスキル

  • utermctl：run / run-many / クイックコマンド
  • SFTP の読み書きと転送の再開、ポートフォワーディングの追加・削除
  • 開いているターミナルセッションの読み取りと入力
  • ペアリング済みの Mac 上のファイルにアクセス
  • Claude Code、Codex、Cursor、CodeBuddy、Antigravity にスキルをインストール
  • デフォルトはオフ、認証情報は uTerm の外に出ない

リモート操作

  • ターミナルミラーリング、音声付きのリモートデスクトップ
  • ウインドウをひとつだけ表示、スマートフォンの画面に合わせてサイズを調整
  • タッチスクリーン / トラックパッドモード、3 本指ジェスチャ
  • 複数ディスプレイ、8 倍拡大、仮想ディスプレイ
  • ロック画面とシステム認証ダイアログをリモートで解除
  • ローカルネットワークでの直接接続、ホールパンチング、セルフホストのリレー

iPhone と iPad

  • ターミナル、ファイル、転送、クイックコマンド、Agent
  • セッションはホストに残り、切断後に自動で復帰
  • ダイナミックアイランド、ロック画面での状態表示、離れても実行を継続
  • キーボードバー：よく使うキー、コマンドのフレーズ、画像とビデオの送信
  • ワークスペースでタブを混在、2 分割表示
  • iPhone Duo の折りたたみ、展開、横向きに対応

同期とプライバシー

  • ホスト、グループ、鍵、クイックコマンドを iCloud で同期
  • ローカルネットワークで暗号化されたプッシュ同期
  • 環境設定をデバイス間で共有
  • Face ID / Touch ID による App ロック
  • ログイン後にバックグラウンドで実行可能、Dock には表示しない
  • アカウント不要、データ収集なし、オープンソース
  • インターフェイスは简体中文、English、繁體中文、日本語、한국어 に対応

プライバシー

uTerm は、ユーザーデータを保存するためのサーバを運営していません。

アカウント不要

インストールしたらすぐに使えます。登録もログインも必要ありません。

データを収集しない

App には解析やトラッキングの仕組みがありません。データはあなたのデバイスと、あなたの iCloud にのみ保存されます。

キーチェーン

パスワードと秘密鍵はシステムのキーチェーンに保存されます。Face ID または Touch ID による App ロックもオンにできます。

オープンソース

App とリレーのソースコードはいずれも AGPL-3.0 で公開しています。自分で監査し、自分で設置できます。

よくある質問

iPhone / iPad 版はどうやってインストールしますか？

現在は TestFlight でパブリックベータを公開しています。iPhone または iPad に TestFlight をインストールしてから招待リンクを開いて参加してください。以降のベータ版は自動で配信されます。

Termius のようなツールとは何が違いますか？

uTerm はアカウント不要で、データはあなた自身の iCloud を通じて同期され、第三者のサーバを経由しません。Mac と iOS のネイティブ App で、コマンドを実行できる AI アシスタントを内蔵し、スマートフォンから Mac のターミナルや画面をリモート操作することもできます。

Windows や Linux には対応していますか？

現在対応しているのは macOS（Apple シリコン）と iOS / iPadOS のみです。サーバ側に要件はなく、SSH でログインできるホストならどれにでも接続できます。

Mac をリモート操作するには何が必要ですか？

Mac とスマートフォンの両方に uTerm をインストールしてください。初回のペアリングでは、スマートフォンに表示される確認コードを Mac に入力します。同じローカルネットワーク内では直接接続し、別のネットワークからはまずピアツーピア接続を試みます。失敗した場合は、自分で設置したリレーを経由します（リレーはコマンドひとつで自分のサーバにインストールできます）。

AI アシスタントは私のデータをどこに送りますか？

あなたが設定したモデルサービスにだけ、あなたの API キーを使って送信します。設定していなければ、何も送信しません。

問題はどこで報告できますか？

GitHub Issues で報告してください。セキュリティ上の問題は、SECURITY.md の手順に従って非公開で報告してください。

Mac과 iPhone을 위한
SSH 터미널 및 서버 도구

터미널은 Ghostty 엔진으로 구동됩니다. 파일 관리, 포트 포워딩, 키, 여러 호스트 병렬 실행, AI 도우미가 하나의 앱에 모여 있고, iPhone으로 Mac을 원격 제어할 수도 있습니다. 코드는 AGPL-3.0으로 공개되어 있으며 계정 가입이 필요 없습니다.

macOS용 다운로드 iPhone 및 iPad용(공개 베타)

macOS 26 이상(Apple 실리콘) · iOS / iPadOS 18 이상 · AGPL-3.0

터미널

터미널은 Ghostty 엔진이 GPU로 그립니다. 출력이 아무리 많아도 스크롤이 매끄럽고, Claude Code나 Codex 같은 전체 화면 프로그램도 Ghostty에서와 똑같이 표시됩니다.

  • 탭과 화면 분할

    탭을 드래그하면 화면이 분할되고, 다시 실행해도 원래 레이아웃 그대로 복원됩니다.

  • 다시 실행해도 이어지는 터미널

    로컬 터미널은 별도 프로세스가 유지합니다. uTerm을 업데이트하거나 예기치 않게 종료된 뒤 다시 열어도 터미널 속 프로그램은 그대로입니다.

  • 연결이 끊겨도 자동으로 다시 연결

    iPhone에서는 셸이 호스트에서 계속 실행됩니다. 다시 연결되면 자동으로 이어 붙고, 끊겨 있던 동안의 출력도 채워 넣습니다.

파일, 포워딩, 키, 일괄 실행

서버 관리에 자주 쓰는 도구를 터미널 곁에 모았습니다.

SFTP 윈도우

독립된 파일 윈도우에서 여러 탭, 드래그 앤 드롭 업로드·다운로드, 다중 병렬 전송을 지원합니다. 파일을 로컬 앱으로 열고 저장하면 호스트로 자동 전송되며, SQLite 데이터베이스는 uTable로 열 수 있습니다.

미리 보기와 편집

작업 공간에서 원격 파일을 열어 구문 강조, Markdown, 이미지 미리 보기를 사용하고, 편집한 뒤 ⌘S로 호스트에 저장합니다. 같은 윈도우 아래쪽에 터미널이 있습니다.

포트 포워딩

로컬, 원격, SOCKS 포워딩을 지원합니다. 모든 호스트의 규칙을 한 패널에서 관리하고, uTerm 실행 시 자동으로 연결되도록 설정할 수 있습니다.

여러 호스트 병렬 실행

선택한 호스트에서 같은 명령을 동시에 실행하고, 호스트별 출력을 칸마다 따로 보여 줍니다. 백그라운드로 보낼 수 있으며, 오류가 난 호스트는 AI에게 맡겨 계속 원인을 찾게 할 수 있습니다.

호스트와 그룹

용도별로 그룹을 만들고 점프 호스트를 지원합니다. 새로 추가할 때 연결을 먼저 테스트하거나, 기존 호스트를 복제하거나, ~/.ssh/config에서 가져올 수 있습니다.

빠른 명령

자주 쓰는 명령을 저장하고 대상 호스트를 지정합니다. 실행 기록은 30일간 보관됩니다. 목표만 설명하고 실행은 AI에게 맡길 수도 있습니다.

키

Ed25519, RSA, ECDSA 키를 생성하거나 가져오며, 암호가 걸린 개인 키도 지원합니다. 키는 키체인에 보관되고 iCloud 키체인으로 동기화됩니다.

알려진 호스트 지문

처음 연결할 때 호스트 지문을 확인하고, 지문이 바뀌면 연결을 차단합니다. 저장된 지문은 여기서 확인하고 삭제할 수 있습니다.

iPhone과 iPad

터미널, 파일, 포트 포워딩, 빠른 명령, AI 도우미를 iPhone과 iPad에서도 똑같이 쓸 수 있고, 호스트와 키는 iCloud로 동기화됩니다. iPhone Duo를 펼치거나 가로로 들면 큰 화면 레이아웃으로 바뀝니다.

  • 호스트에 남아 있는 세션

    셸은 호스트의 유지 프로세스가 실행합니다. 백그라운드로 전환하거나, 네트워크가 바뀌거나, 시스템이 앱을 종료해도 돌아오면 자동으로 이어지고 끊겨 있던 동안의 출력도 채워집니다.

  • 키보드 막대

    esc, tab, ctrl과 방향 키를 제공하고, claude, codex 같은 자주 쓰는 명령을 입력할 수 있습니다. 클립보드나 사진 보관함의 이미지와 비디오를 호스트의 AI 프로그램으로 보낼 수도 있습니다.

  • Dynamic Island와 백그라운드 실행

    Claude Code가 확인을 기다리거나 완료하거나 오류가 나면 Dynamic Island와 잠금 화면에 상태가 표시됩니다. 탭을 길게 눌러 ‘나간 후에도 계속 실행’을 선택하면 다른 앱으로 전환해도 연결이 유지됩니다.

  • 탭과 화면 분할

    터미널 탭과 파일 탭이 한 작업 공간에 있고, 드래그해서 두 칸으로 나눌 수 있습니다. 스크롤백에서 검색도 가능합니다.

Mac 원격 제어

Mac에서 열어 둔 터미널을 iPhone에서 이어서 쓰거나, Mac 화면을 보며 조작할 수 있습니다. 다른 Mac을 제어하는 쪽으로 쓸 수도 있습니다.

터미널 미러링Mac에서 새로 연 터미널이 자동으로 휴대폰에 나타납니다. 양쪽에서 동시에 입력할 수 있고, 화면은 한 칸 한 칸 똑같으며, Claude Code의 실행 상태도 동기화됩니다.
원격 데스크톱하드웨어 인코딩으로 지연이 짧고 소리도 함께 전달됩니다. 디스플레이를 전환하고 최대 8배까지 확대할 수 있으며, 디스플레이가 연결되지 않은 Mac에는 휴대폰 화면에 맞춘 가상 디스플레이를 만듭니다.
제스처트랙패드와 터치스크린 두 가지 모드를 제공하며, 세 손가락으로 쓸어 데스크톱을 전환하거나 Mission Control을 열 수 있습니다.
원격 잠금 해제휴대폰에서 암호를 입력해 Mac의 잠금을 해제하거나 시스템 인증 창을 통과할 수 있습니다. 암호는 휴대폰에만 저장되며 사용할 때 Face ID 인증이 필요합니다.
Mac의 파일SSH를 켜지 않고도 페어링된 Mac의 파일을 탐색하고 업로드·다운로드할 수 있습니다. 로컬 폴더를 제어 중인 Mac에 공유할 수도 있으며, 기본값은 읽기 전용입니다.
Mac으로 Mac 제어다른 Mac으로 제어할 때도 화면, 터미널, 단일 윈도우 보기를 똑같이 쓸 수 있습니다.
기기 그룹휴대폰, 태블릿, Mac을 같은 기기 그룹에 넣으면, 그룹 안의 기기 한 대에서 확인하는 것만으로 새 기기를 추가할 수 있습니다. 한 대씩 페어링할 필요가 없습니다.
업데이트 중에도 끊기지 않는 연결원격 제어는 별도의 백그라운드 프로세스에서 실행됩니다. Mac의 uTerm을 업데이트하거나 예기치 않게 종료되어도 기존 연결은 그대로 유지됩니다.
2.4 신규

윈도우 모드

Mac의 윈도우 하나만 봅니다. Mac이 해당 윈도우를 휴대폰 화면에 맞는 크기로 조절하고 내용도 그에 맞춰 다시 배치하며, 끝내면 원래 크기로 돌아갑니다.

  • 텍스트 크기

    ‘가장 선명’에서는 Mac의 픽셀이 휴대폰 픽셀과 1:1로 대응하고, ‘표준’에서는 텍스트가 Mac에서와 같은 크기로 보입니다. 더 크게 키울 수도 있습니다.

  • 터치스크린 모드

    원하는 위치를 바로 탭합니다. 한 손가락 드래그는 스크롤, 길게 누른 뒤 드래그는 끌어 놓기, 두 손가락 탭은 오른쪽 클릭입니다.

  • 독립 키보드 및 마우스

    입력이 해당 윈도우로 바로 전달되어 Mac의 포인터가 움직이지 않습니다. 윈도우가 가려져 있어도 조작할 수 있고, Mac 앞의 사용자는 자신의 키보드와 마우스를 동시에 쓸 수 있습니다.

  • 맨 앞에 유지

    윈도우가 가려지면 macOS가 다시 그리기를 멈춥니다. 이 옵션을 켜면 보는 동안 해당 윈도우가 항상 맨 앞에 있습니다.

로컬 네트워크 직접 연결

같은 네트워크 안에서는 직접 연결하므로 지연이 가장 짧습니다.

P2P 연결

같은 네트워크에 있지 않으면 먼저 홀 펀칭으로 직접 연결을 시도하며, 서버를 거치지 않습니다.

자체 구축 릴레이

직접 연결할 수 없을 때는 직접 배포한 릴레이를 거쳐 전달합니다. 릴레이는 암호화된 데이터만 전달할 뿐 내용을 읽을 수 없습니다.

AI 도우미

도우미가 현재 호스트에서 명령을 실행하고 결과를 읽은 뒤 다음 단계를 정합니다. 모든 명령은 설정한 안전 수준에 따라 확인을 거쳐 실행됩니다.

  • 안전 수준

    ‘단계마다 확인’, ‘읽기 전용 자동’, ‘AI 승인’ 중에서 고를 수 있습니다. 민감한 작업이 포함되거나 위험도를 판단할 수 없는 명령은 항상 사람이 확인해야 합니다.

  • 모델 제공자

    자신의 API 키로 Anthropic, OpenAI 또는 호환 API에 연결하고, 모델과 사고 깊이를 선택할 수 있습니다.

  • 다른 AI 코딩 도구에서 사용

    설정에서 Claude Code, Codex, Cursor, CodeBuddy, Antigravity용 uTerm 스킬을 설치할 수 있습니다. 이 도구들은 uTerm을 통해 저장된 호스트로 명령을 실행하고, 파일을 전송하고, 터널을 만들며, 암호는 전달받지 않습니다.

# 用 uTerm 操作远程主机

地址、密码、私钥、口令、跳板机配置全程留在 uTerm 和钥匙串里，
你一个字节也拿不到，也不需要。

모든 기능

uTerm의 현재 기능을 분류별로 정리했습니다.

터미널

  • Ghostty 엔진과 GPU 렌더링, Claude Code·Codex 등 전체 화면 프로그램을 정확하게 표시
  • 탭과 드래그 분할, 다시 실행하면 레이아웃 복원
  • 로컬 터미널과 SSH 터미널은 uTerm을 다시 실행하거나 업데이트한 뒤 자동으로 이어짐
  • 스크롤백에서 검색(⌘F)
  • Claude / Codex 실행 상태를 탭에 표시하고, 직접 처리해야 할 때 알림
  • 실행 중인 프로그램이 있는 탭을 닫기 전에 확인
  • 터미널 ⇄ 에이전트 원클릭 전환

파일

  • SFTP 윈도우와 작업 공간 사이드바, 여러 탭
  • 드래그 앤 드롭 업로드·다운로드, 다중 병렬 전송
  • 미리 보기, 바로 편집, ⌘S로 호스트에 저장
  • 로컬 앱으로 열고, 저장하면 자동 전송
  • SQLite 데이터베이스는 uTable로 열기
  • 폴더 삭제 시 진행 상황 표시, 도중에 취소 가능

호스트와 연결

  • 그룹, 고정, 검색, 키보드 조작
  • 점프 호스트, 연결 테스트, 새 호스트로 복제
  • ~/.ssh/config에서 가져오기
  • Ed25519 / RSA / ECDSA 키, 키체인에 보관
  • 알려진 호스트 지문 확인
  • 포트 포워딩 -L / -R / SOCKS, 실행 시 자동 연결 가능

AI

  • 에이전트가 명령을 실행하고 결과를 읽어 결론 제시
  • 단계마다 확인 / 읽기 전용 자동 / AI 승인의 3단계
  • 실행 카드: 승인, 진행 상황, 출력, 종료 코드
  • 자신의 모델 제공자 연결, 모델과 사고 깊이 선택
  • 상호 작용이 필요한 명령은 새 터미널 윈도우에서 실행
  • 대화 기록, 기본 180일 보관

명령줄 및 스킬

  • utermctl: run / run-many / 빠른 명령
  • SFTP 읽기·쓰기와 이어받기, 포트 포워딩 추가·삭제
  • 열린 터미널 세션 읽기 및 입력 보내기
  • 페어링된 Mac의 파일에 접근
  • Claude Code, Codex, Cursor, CodeBuddy, Antigravity용 스킬 설치
  • 기본적으로 꺼져 있으며, 자격 증명은 uTerm 밖으로 나가지 않음

원격 제어

  • 터미널 미러링, 소리가 함께 전달되는 원격 데스크톱
  • 윈도우 하나만 보기, 휴대폰 화면에 맞춰 크기 조절
  • 터치스크린 / 트랙패드 모드, 세 손가락 제스처
  • 다중 디스플레이, 8배 확대, 가상 디스플레이
  • 잠금 화면과 시스템 인증 창 원격 잠금 해제
  • 로컬 네트워크 직접 연결, 홀 펀칭, 자체 구축 릴레이

iPhone과 iPad

  • 터미널, 파일, 포워딩, 빠른 명령, 에이전트
  • 세션은 호스트에 남고, 끊기면 자동으로 다시 연결
  • Dynamic Island와 잠금 화면 상태, 나간 후에도 계속 실행
  • 키보드 막대: 자주 쓰는 키, 명령 문구, 이미지·비디오 보내기
  • 작업 공간에 탭 혼합 배치, 두 칸 분할
  • iPhone Duo의 접기, 펼치기, 가로 모드에 최적화

동기화와 개인정보 보호

  • iCloud로 호스트, 그룹, 키, 빠른 명령 동기화
  • 로컬 네트워크 암호화 푸시 동기화
  • 환경설정을 기기 간에 공유
  • Face ID / Touch ID 앱 잠금
  • 로그인 후 백그라운드에서 실행 가능, Dock에 표시 안 함
  • 계정 불필요, 데이터 수집 없음, 오픈 소스

자주 묻는 질문

iPhone 및 iPad용은 어떻게 설치하나요?

현재 TestFlight 공개 베타로 제공됩니다. iPhone 또는 iPad에 TestFlight를 설치한 뒤 초대 링크를 열어 참여하면, 이후 베타 버전이 자동으로 제공됩니다.

Termius 같은 도구와 무엇이 다른가요?

uTerm은 계정이 필요 없고, 데이터는 사용자 자신의 iCloud로 동기화되어 타사 서버를 거치지 않습니다. Mac과 iOS용 네이티브 앱이며, 명령을 실행할 수 있는 AI 도우미가 내장되어 있고, 휴대폰으로 Mac의 터미널과 화면을 원격 제어할 수 있습니다.

Windows나 Linux를 지원하나요?

현재는 macOS(Apple 실리콘)와 iOS / iPadOS만 지원합니다. 서버 쪽에는 요구 사항이 없으며, SSH로 로그인할 수 있는 호스트라면 어디든 연결할 수 있습니다.

Mac을 원격 제어하려면 무엇이 필요한가요?

Mac과 휴대폰 모두에 uTerm을 설치해야 합니다. 처음 페어링할 때 휴대폰에 표시된 확인 코드를 Mac에 입력합니다. 같은 로컬 네트워크에서는 직접 연결하고, 다른 네트워크에서는 먼저 P2P 연결을 시도하며, 실패하면 직접 배포한 릴레이를 거칩니다(명령 하나로 서버에 설치할 수 있습니다).

AI 도우미는 제 데이터를 어디로 보내나요?

사용자가 설정한 모델 제공자에게만 사용자의 API 키로 보냅니다. 설정하지 않으면 아무것도 보내지 않습니다.
